API kľúče

Každý kľúč povoľuje odosielanie správ. Po vytvorení sa jeho hodnota zobrazí raz.

Prvé volanie

Nastav premennú PINGDECK_KEY na svoj API kľúč.

BASH
curl '{{endpoint}}' \
  -H "Authorization: Bearer $PINGDECK_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"title":"Monitoring","message":"Všetko beží."}'

Voliteľné parametre sú deviceId alebo group, url, ttl a urgency.
